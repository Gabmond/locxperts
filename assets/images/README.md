# LocxPert image assets

`locxpert-wordmark.png` is the horizontal logo used in the header. `locxpert-logo.png` is the square brand mark used in the footer.

Add approved website photos in this folder. Suggested names include `hero-locs.jpg`, `starter-locs.jpg`, `loc-retwist.jpg`, `loc-repair.jpg`, `loc-styling.jpg`, `loc-extensions.jpg`, and `about-loctician.jpg`.

Add an `<img>` with an appropriate `src` and alt text inside the relevant labelled `<figure class="media-placeholder ...">`, then add `media-placeholder--photo` to that figure. Keep the appropriate `media-placeholder--portrait`, `--landscape`, or `--square` ratio class. Use empty alt text for decorative images. Do not label stock imagery as LocxPert client work.
